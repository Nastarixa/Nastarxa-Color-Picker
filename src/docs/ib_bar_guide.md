## LT INDICATOR

Thin strip on the far left of the bar.

| Color | State |
| --- | --- |
| Blue | Light Table active, ready |
| Red | Light Table closed or LT Lock ON |
| White | Empty slot selected |

## IB BAR

Visual map of the current inbetween split, e.g.

    50 |-----|-----|>

Updates whenever another slot is selected. Turns to "- disabled -" when Animation requirement is off.

## EMPTY BUTTON

Clears / resets the Light Table entirely.
Shortcut: Ctrl+Backtick

## E>S / S>E BUTTON

Toggles the inbetween direction:

- S>E — smaller number layer above edit layer
- E>S — bigger number layer above edit layer

## IB NUMBER BUTTONS

Pick an inbetween percentage (25 / 33 / 50 / 66 / 75 ...). Sends the matching Ctrl+number to CSP and refreshes the Light Table. Hover shows the split for each number.
