## FEATURE TOGGLES

| Toggle | Switch / Button |
| --- | --- |
| Space Nav | Ctrl+F5 / Hand button |
| CapsLock Mod | Ctrl+F6 / Caps button |
| Tab Combos | Ctrl+F7 / Tab button |
| LWin Right-click | Ctrl+F9 / Win button |
| LT Lock | Ctrl+F2 / Padlock button |
| Auto Save | Ctrl+F4 / Disk button |
| Cursor Color Info | Palette button on IB bar |
| Reset Keys | Ctrl+F8 / Reset button |

### Space Nav

ON: Hold Space and drag to pan the canvas. Variants: Ctrl+Space drag, Shift+Alt+Space drag.
OFF: Space passes through to CSP normally.

### CapsLock Mod

ON: Hold CapsLock to use it as a modifier key (works like Ctrl/Shift/Alt combos), tap it to trigger your assigned CapsLock slots. While typing it acts as normal CapsLock.

### Tab Combos

ON: Tab works as a modifier key for shortcuts and pie quick keys.
OFF: Tab passes through to CSP normally.

### LWin Right-click

ON: Pressing LWin sends a Right Mouse Click instead of opening the Start Menu.

### LT Lock

ON: Locks the Light Table state so switching cels/frames does not change it. IB bar is disabled while locked.

### Auto Save

ON: Auto-saves the current CSP file every N seconds while CSP is active (interval is set in System Settings).

### Cursor Color Info

ON: Shows a live color readout of the pixel under the cursor (follows cursor or fixed position, mode in System Settings).

### Reset Keys

ON: Watchdog auto-releases stuck Ctrl, Shift, Alt or Win modifiers when their physical key is already up.
Manual release anytime: Ctrl+Alt+Shift+Backspace

## STATUS BAR

The wide bar right of the timer row shows one of three states:

- Lap text — Last recorded timer lap (teal)
- Hotkey Off — Toolkit hotkeys paused (red)
- Mode name — Currently active mode, shown in the mode's color

Drag the bar to move the IB window.

- Alt+Click — Cycle to next mode
- Double-click — Open the mode selector
